# 2026-10-06 — UL-012b — Évaluation des décisions et rapport de mesure

Base : `3aeb669` (branche `claude/quirky-darwin-v4is1f`).

## Objectif

Permettre à un pilote de mesurer la valeur des propositions sans tableur externe, uniquement à partir de ce qui est enregistré (DEBT-009).

## Changements

- Domaine : `QUALITY_LABELS`, validation de cohérence évaluation/décision, évaluation dans la décision et l'audit ; module `report.ts` (fonction pure) ; `QueryService.qualityReport` ; ports `listRecommendationDigests` / `listDecisionDigests` (mémoire et PostgreSQL) ; scénario partagé.
- Base : migration `0008_decision_quality.sql` (colonne, contraintes, index).
- API : `quality` dans `DecisionBody` et le détail ; `GET /v1/reports/quality` ; OpenAPI régénéré.
- Interface : sélecteur « Évaluation de la proposition » (boutons désactivés en cas d'incohérence, avec explication), affichage de l'évaluation sur une proposition close, page « Mesure ».
- Décision : [ADR-0011](../adr/0011-mesure-pilote.md).

## Limites

- Données fictives : les chiffres capturés ne disent rien de la valeur réelle.
- Couverture et gain de temps non mesurés (nécessitent l'équipe pilote).
- Catégories d'évaluation proposées, à confirmer par le responsable du pilote (Q-010).

## Suite

UL-008 / UL-007 dès qu'une source, une doctrine validée et un responsable du pilote sont disponibles.

## Défauts trouvés et corrigés pendant le lot

- Sécurité : `REVOKE … FROM PUBLIC` exécuté après le transfert de propriété d'une fonction `SECURITY DEFINER` était sans effet ; le rôle API pouvait appeler `provision_tenant`. Ordre corrigé, test d'ACL ajouté (ADR-0004).
- Sécurité : un jeton d'identité signé par une clé étrangère était accepté ; vérification de signature désormais systématique (`enableNonRepudiationChecks`).
- Journaux : le code et l'état OIDC apparaissaient dans les URL journalisées ; sérialiseur de requête limité au chemin, absence vérifiée.
- Abstention « source périmée » comptée par règle au lieu d'une par sujet ; corrigé.
- Clé étrangère `analysis_id` violée par l'ordre d'insertion ; contrainte différée.
- Mise à jour pg-boss refusée (« queue policy cannot be changed ») ; mise à jour sans politique.
- Interface : retour de décision perdu au remontage, sélecteurs ambigus, focus déplacé au premier chargement ; corrigés, recette stabilisée.
- Course dans le test de formulation du worker (usage enregistré avant application) ; le test attend désormais l'événement d'audit.
- CI e2e : Playwright démarre ses serveurs avant `globalSetup` ; base préparée avant `playwright test`.
